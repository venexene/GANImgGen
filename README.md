# Генерация изображений с применением генеративно-состязательных нейронных сетей (GAN)

## Описание проекта
Курсовая работа в которой были реализованы и исследованы базовые GAN.

Использованы датасеты: **MNIST** и **CelebA**

## Ключевые аспекты работы

- Была реализована полносвязная GAN для генерации изображений на основе датасета MNIST
- Далее была спроектирована сверточная архитектура DCGAN для той же задачи генерации рукописных цифр
- Была реализована улучшенная DCGAN для генерации изображений лиц на основе датасета CelebA

## Структура репозитория
- GAN_MNIST/ - ноутбук с обучением модели полносвязной GAN для генерации рукописных цифр
- DCGAN_MNIST/ - ноутбук с обучением модели DCGAN для генерации рукописных цифр
- DCGAN_FACES/ - ноутбук с обучением модели DCGAN для генерации изображений лиц
